# FilmVerse

## Запуск локально

1. Створи обліковий запис на [TMDB](https://www.themoviedb.org/) і згенеруй API Read Access Token у [налаштуваннях API](https://www.themoviedb.org/settings/api).
2. Скопіюй `.env.example` у `.env` і додай токен у `TMDB_ACCESS_TOKEN`. Файл `.env` не слід додавати до Git.
3. Встанови залежності та запусти Flask:

   ```powershell
   pip install -r requirements.txt
   python run.py
   ```

Сторінка отримує каталог і пошук з TMDB через сервер Flask; токен не передається браузеру. Окремий каталог безкоштовних фільмів завантажується з Internet Archive і не потребує API-токена.

Натисни на картку фільму або серіалу, щоб відкрити сторінку з описом, акторським складом, трейлером, оцінками та схожими стрічками. Посилання на сторінку деталей можна скопіювати або відкрити напряму.

Повні безкоштовні фільми доступні в розділі «Безкоштовні» через вбудований плеєр Internet Archive. Каталог обмежений фільмами, які сервіс позначає як Public Domain і для яких є MPEG-4 файл; перед переглядом перевіряй права та доступність на сторінці першоджерела. Каталог не містить повних версій сучасних комерційних фільмів.

Профіль FilmVerse наразі гостьовий: ім’я та список зберігаються локально в браузері, без реєстрації чи синхронізації між пристроями. Переходи між деталями, профілем, списком, каталогом та інформаційними сторінками підтримують кнопки браузера «Назад» і «Вперед» та відновлюють попередній пошук, фільтр і позицію прокрутки.
